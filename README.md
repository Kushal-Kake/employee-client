# Employee Data Visualization (Client)

This is the frontend for the Employee Data project.
It provides a simple UI for authentication and employee data visualization.
---

## 🚀 Features

- Register/Login with email and password
- View employee data after login
- Secure routes (JWT-based auth)
- Interactive charts for employee performance
- API integration with backend

---

## 🛠️ Tech Stack

- **React + TypeScript**
- **Vite**
- **pnpm**
- **TailwindCSS**
- **Axios**

---

## 📂 Project Setup

### 1. Clone Repository

```bash
git clone <client-repo-url>
cd <client-folder>
pnpm install
pnpm dev
```
